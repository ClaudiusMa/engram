# Connect Project Workflow

> This routed procedure is extracted from the root contract. Load it only for this route; repository-relative paths are relative to the Engram root.

An explicit connection request enables the optional integration for the named project. Load [schema/workflows/productlab.md](../../schema/workflows/productlab.md) for ProductLab. For another external project, use its user-supplied location and the same source-pointer contract without requiring ProductLab or its catalog. Ordinary ingest, query, and artifact work must not initiate a connection.
